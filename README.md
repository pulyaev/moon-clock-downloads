# Moon Clock · Desktop downloads

[Project website and downloads](https://moon.puliaev.com/downloads.html) · [Releases](https://github.com/pulyaev/moon-clock-downloads/releases)

Natural countdown dial, compact tray/menu-bar preview, pin above other windows, and local device alarms. No Moon Clock account required. The interface supports Russian, English, Simplified Chinese and Japanese.

- **Windows:** x64 and ARM64 portable ZIP. Extract the entire folder and run `MoonClock.exe`; exit the old version from the tray before updating. Windows 11 recommended; x64 also supports Windows 10 22H2. Requires Microsoft Edge WebView2 Runtime. Unsigned Preview MSIX files are provided separately for testing.
- **macOS 15+:** Apple Silicon and Intel ZIP/DMG. Drag Moon Clock into Applications. These previews use an ad-hoc integrity signature, without Apple Developer ID or notarization; Gatekeeper may require approval in System Settings.

This repository contains distributions, checksums and release information. Source is maintained in a separate private repository. Each release includes SHA-256 and build provenance. Preview status does not certify GPS, notification delivery after sleep/exit, or Store acceptance.
